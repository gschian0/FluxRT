# Cover Letter: GPU and Cloud Support for Real-Time Media Research

Dear GPU Services and Cloud Infrastructure Team,

I am writing to request support for my ongoing live research project, Symbiosis and Sweat: The Single-Operator Broadcast. This work operates as a real-time media processor under Schiano Research, combining live internet television, internet radio, AI generation, and cloud orchestration into a single operator-led pipeline.

My goal is to use managed GPU services and raw cloud processors to build and demonstrate a practical broadcast system that can be understood, tested, and adapted by other artists, researchers, and technologists. The project is not only a technical workflow; it is also an educational platform. I want to show people how to work directly with cloud-native compute, live inference, and real-time media routing without hiding the underlying infrastructure behind opaque tools.

The system is designed around efficient use of modern hardware, including L4-class GPUs and low-bit model workflows, to keep the broadcast feasible while remaining accessible. It integrates live audio and video processing, spatial sound experimentation, and generative media into a single operational environment. I am also extending the work toward local text-to-speech, 3D broadcasting, and spatial rendering so that the pipeline can serve as a teaching tool for future media systems.

Support from your GPU and cloud services would help me continue developing this work in a way that is both technically rigorous and publicly useful. I would use the resources to educate people on how to engage directly with raw cloud services: how to provision compute, move media through live pipelines, and build resilient systems for research, performance, and broadcasting.

I believe this project demonstrates how cloud infrastructure can support not just production, but learning, experimentation, and creative access. With the right support, I can keep refining the system and share the process openly so others can learn from it.

Thank you for your time and consideration.

Sincerely,

Gennaro Schiano
Schiano Research
